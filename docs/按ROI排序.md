## 关键决策记录

### 命中回测（已完成基础设施）

- `SignalEvent.meta` 携带 `hit / leadSec / hitAt`；6 h 内价到自动回写。
- 面板显示「命中率 / 平均领先 / 最大偏离」三件套。
- **已完成**：累计统计升级为「近 30 天时序曲线」（7 日滚动命中率 + 每日信号数柱，悬停明细）。
- **下一步**：周报导出（#11）。

### 持仓联动（已完成基础设施）

- 成本线 + 「到本」角标 + ±1 % 闪烁。
- **已完成**：盯盘页区分浮盈 / 浮亏；点击盈亏数字查看现价、成本、股数与收益率；一键复制持仓盈亏摘要，缓存报价会标注。
- **下一步**：AI 减仓建议（C.4）。

### 本地 LLM（已完成协议层）

- `LLMProvider` / `ProviderRegistry` / `OpenAICompatibleProvider` 已就位。
- **下一步**：新增 `OllamaProvider` / `LocalHTTPProvider`（A.3）。

### Rust 后端（2026-09-18 敲定架构）

- **决策**：独立服务（NAS / 旧 Mac）+ SQLite + Actix-web 4 + 渐进式 4 阶段。
- **完整设计**：见 [`架构-Rust后端.md`](架构-Rust后端.md)。
- **阶段 1**：行情网关 —— 3–4 天，是 ROI 最高的前期投入。
- **前置价值**：阶段 1 跑通后，§F 数据接入、§G 跨设备 全部自然展开。

## 不做什么（保持克制）

- ❌ 自动下单：合规风险 + 用户决策权让渡。
- ❌ 多账号资产管理 / 跟单：偏离个人工具定位。
- ❌ Web 版 / 移动端（iOS 只读除外）：先把 macOS 体验做透。
- ❌ 第三方数据源再接 N 个：先把现有新浪 / 腾讯 / 东财三个用稳。
