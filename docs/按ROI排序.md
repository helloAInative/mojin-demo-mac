## 关键决策记录

### 推荐算法可靠性（2026-09-25 新增）

- **事件**：09-24 大盘急跌，09-23 买入票跟跌；根因是漏斗无 A 股大盘闸门 + 动量偏置。
- **决策**：先 pause / 降权，再谈扩池与推送；胜率必须按 regime 展示。
- **清单分层**：§A.10 市场闸门 → §A.11 信号分档 → §A.12 池子/组合 → §A.13 执行过程 → §A.14 评估治理。
- **验收**：见 [`未来演进方向.md`](未来演进方向.md)「最新演进方向 · 本阶段成功标准」。

### UI 精细化（2026-09-25 新增 §I）

- **动机**：可靠性字段（情绪灯 / regime / 执行曲线 / ES·DD / 买卖点）已齐，精选卡默认态过载，读不动 ≈ 能力未交付。
- **决策**：不换皮肤、不接 UI 库；先 I.1 三层折叠 + I.2 令牌 + I.3 数字格式；可与影子盘并行，不抢算法排期。
- **验收**：见演进文档 §I.9。

### 命中回测（已完成基础设施）

- `SignalEvent.meta` 携带 `hit / leadSec / hitAt`；6 h 内价到自动回写。
- 面板显示「命中率 / 平均领先 / 最大偏离」三件套。
- **已完成**：累计统计升级为「近 30 天时序曲线」（7 日滚动命中率 + 每日信号数柱，悬停明细）。
- **下一步**：并入 regime 分层，避免总命中率掩盖急跌日失效。

### 持仓联动（已完成基础设施）

- 成本线 + 「到本」角标 + ±1 % 闪烁。
- **已完成**：盯盘页区分浮盈 / 浮亏；点击盈亏数字查看现价、成本、股数与收益率；一键复制持仓盈亏摘要，缓存报价会标注。
- **已完成**：AI 减仓建议（C.4）。

### 本地 LLM（已完成协议层）

- `LLMProvider` / `ProviderRegistry` / `OpenAICompatibleProvider` 已就位。
- **下一步**：可靠性冲刺结束后再做 `OllamaProvider` / `LocalHTTPProvider`（A.3）。

### Rust 后端（2026-09-18 敲定架构；四阶段已收官）

- **决策**：独立服务（NAS / 旧 Mac）+ SQLite + Actix-web 4 + 渐进式 4 阶段。
- **完整设计**：见 [`架构-Rust后端.md`](架构-Rust后端.md)。
- **现状**：行情 / AI / 数据 / 推送四阶段 + §A.5 推荐 + §A.9/A.10 均已在服务端落地。

## 不做什么（保持克制）

- ❌ 自动下单：合规风险 + 用户决策权让渡。
- ❌ 多账号资产管理 / 跟单：偏离个人工具定位。
- ❌ Web 版 / 移动端（iOS 只读除外）：先把 macOS 体验做透。
- ❌ 第三方数据源再接 N 个：先把现有新浪 / 腾讯 / 东财三个用稳。
- ❌ 可靠性未达标前扩推荐池 / 开 TG 推送：坏信号外溢成本高于功能收益。
- ❌ 为 UI 打磨换皮肤或引入第三方组件库：只做信息架构与令牌（§I）。
